# Futureboard Studio 2026.11.1-beta2.0.0

Changes since **2026.10.16-beta1.4.4**.

## Voxtune: vocal tuning in the Editor panel

A new **Voxtune** tab in the Editor panel tunes the selected audio clip's
take, following Studio's transport through the clip.

- **Notes, scale and solfège**:
  - notes are drawn as capsules coloured by how far they sit from the scale;
  - each has its pitch thread and an off-key tag;
  - a solfège lane and an overview strip run along the editor.
- **Tools**: pitch, drift, time, formant and level, with Correct for the
  whole take, cut, join, mute and reset, ornaments and accents, and its own
  history.
- **Stretching keeps the pitch.** Making a note longer or shorter spreads
  its sung audio over the new length without moving its pitch or formants,
  and the stretched note can still be tuned. Joins between notes crossfade,
  so moved or resized notes no longer click.
- **Apply to clip** renders a new version of the clip as one undo step. The
  original take is kept beside it, so the clip is always re-edited from
  the original.

## Plug-ins

- **BurnLimit**:
  - new **Loud** and **Safe** styles;
  - knee, stereo link amount, unity-gain monitoring and dither;
  - 2×/4×/8× oversampling;
  - BS.1770 loudness metering (momentary, short-term, integrated, LRA,
    true peak);
  - the ceiling now reaches −12 dB.
- **EQ-Z8 and EQ-ZX**: 12/24/48 dB/oct cuts and a dynamics ratio. EQ-ZX
  adds Left and Right band channels, a mix control and auto gain. Bands now
  switch on as soon as you drag their node.
- **Zapp** (new): a saturator with six characters (tape, tube, transistor,
  diode, fold, crush), drive and bias, tone cuts and tilt, mix,
  stereo/mid/side placement, oversampling, auto gain and nine presets.
- **New editors for BurnLimit, EQ-Z8, EQ-ZX, Zapp and Rodhareist.** The
  meters, curves, analyser and loudness shown are read from the running DSP.
  Phase modes and an external sidechain do not exist yet and are shown
  disabled.
- **Rodhareist**:
  - Home, Explore, Pedalboard and Settings pages, an input tuner, tap tempo
    and footswitches;
  - a new Stereo Delay;
  - each block (except amp and cabinet) can run on L+R, L or R;
  - input and master level knobs;
  - the NAM capture and IR are saved with the project and reloaded.
- **WhiteSharp**:
  - a redesigned editor built around the pitch ring and band;
  - pitch tracking follows a whole note instead of frame by frame;
  - Pentatonic is now **Major Pentatonic** and **Minor Pentatonic**, picked
    from a scale dropdown that shows each scale's notes in your key.
- **WrapSynth**: wavetable engine, filters, envelopes, LFOs, presets and
  pages.
- **Fixed: AirBoost's de-esser cut far deeper than set.** −6 dB cut about
  −20 dB and deeper settings removed the band; it now cuts by the depth
  you set.
- **Fixed: dragging a Duckstep point between two close neighbours crashed
  Studio.** Adding a point on top of another is refused with a notice.
- **An open built-in editor shows the loaded project's settings** after a
  project loads, instead of defaults until it is reopened.
- **Plug-in latency is reported for every plug-in in the host**, not just
  the first, so delay compensation sees all of them.
- **Embedded plug-in editors keep keyboard focus on Windows.**

## Mixer

- **SHOW** buttons hide or show strip sections; **Narrow/Wide** strips;
  strips name their input; **Clear solo** and **Add Track** in the header.
- The channel tree has an eye to show or hide a channel, and M/S buttons
  that match the strips.
- Each channel's **INSERTS** header has a power button that bypasses every
  effect on that channel (master included) in one undo step.
- **A new track appears in the Mixer** and scrolls into view (Preferences >
  Editing can turn this off). The selected track stays in step between the
  arrangement and the mixer.
- **The dB scale beside a fader now matches the fader**, so the fader sits
  on the number it reads.
- Meters are painted over cached strips, which makes the mixer lighter
  while playing.
- The Mixer and MIDI Editor windows have a native menu bar on Windows.

## Arrangement, recording and rendering

- **Ctrl+click a bar on the ruler to loop it** (Cmd+click on macOS). Click
  the same bar again to turn the loop off, or Ctrl+drag to loop several
  whole bars.
- **Freeze, Render in Place, Render Selection, Flatten and Consolidate.**
  Freeze renders a track, plays the file and turns its plug-ins off until
  Unfreeze; Render in Place adds a rendered track and mutes the source.
- **Takes**: only the take you hear stays selected, and takes settle when
  a clip moves.
- **Play/Stop returns to where you moved the playhead while playing.**
- **ARA edits travel with a clip** moved to another track.
- **Delay compensation**:
  - can be bypassed while recording (setting);
  - stays aligned across buffer-size changes, freeze and render;
  - freeze, render in place and stems are trimmed by each channel's own
    latency.
- **JAM sessions**: takes recorded along to a jam are moved back by the
  measured arrival latency ("Auto Offset from JAM Session", on by default).
  The round trip is no longer compensated twice.
- **Offline export matches playback**: it uses the same block size as the
  live device, so automation lands on the same samples, and a plug-in block
  is never written half-finished.
- **Export pauses playback** before an offline render starts.

## Windows, dialogs and controls

- **Loading a project names each plug-in** as it is installed ("Loading
  Plugin 1/4: AirBoost on Vocal 1").
- Dialogs open in a native Windows frame; loading windows stay on top.
- The transport bar is taller, with larger readouts.
- Sliders follow the pointer's travel; knobs have a longer drag span.
- Select menus stay inside the window and open upward when there is no
  room below.
- **Professional**: Settings re-reads the license when it opens, so ASIO
  appears after the Launcher renews it, without a restart.

## Crash handling

- **Crash reports are written again.** The crash handler now starts even
  without an upload address, and a crash in Studio's own code is recorded
  too.
- **After a crash, Studio asks whether to relaunch it** (Windows). The
  relaunched Studio starts with the same settings it was first started
  with.

## Removed

- The experimental **DAUx Direct** audio backend from 2026.10.16 is
  removed.

## Under the hood

- Studio now runs from the `FutureboardEngine_x64` library next to a small
  launcher executable; both ship together in the installer.

## Known issues

- **Realtime** export can fail with "the realtime render fell behind" on
  some projects. **Offline** export is not affected.
- A built-in editor kept open while switching projects shows "stopped" and
  empty meters until it is closed and reopened.
