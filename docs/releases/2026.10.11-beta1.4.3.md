# Futureboard Studio 2026.10.11-beta1.4.3

Changes since **2026.10.1-beta1.4.2**.

## SoundFont Player: MIDI tracks drive the sixteen parts

The Soundfont Multi window now sets up its own MIDI tracks. Each channel
has a **+** that creates a MIDI track playing that part, named after its
preset and placed under the instrument, or puts an existing MIDI track on
the channel; **Disconnect** takes it off again. **Add MIDI Tracks** creates
one for every part that has none yet. Each change is a single undo step.

- **Mute and solo on a MIDI track now work** when it plays another track's
  instrument. Muting it silences only its notes; soloing it keeps the
  instrument audible and silences the instrument's other MIDI tracks.
  Previously mute did nothing and solo silenced the instrument entirely.
- **A hardware keyboard plays the MIDI track's channel**, the way the piano
  roll already did, so live playing and recording reach the right part.
- **A MIDI track's bank and program select its part's preset.** The part
  shows the program's preset (marked **PRG**), and picking a preset for that
  part in the browser updates the track's program, so the two always agree.
  Drum kits work on any channel this way (GM/GS channel 10, or the XG drum
  bank anywhere).
- **Fixed: variation-bank presets played the wrong sound.** A preset in
  banks 1–127 (a GS font's variation tones) played the bank 0 sound of the
  same program, in both Single and 16-channel mode.

## DAUx Direct audio backend (Windows, experimental)

A new **DAUx Direct** backend in Audio Settings streams straight to the
audio driver's kernel pins (DAUx-KS kernel streaming), bypassing the
Windows audio engine. It drives USB audio class devices with about 3 ms of
output latency at 1 ms buffers.

## Instruments and plug-ins

- **Quick Sampler** and **Slicer** — new sample instruments with native
  editors. **Drum Sampler** now has 64 pads and multi-output routing.
- **WhiteSharp** — rebuilt as a built-in pitch corrector: scale targeting,
  retune speed, humanize, flex-tune and natural vibrato, Classic mode,
  Create Vibrato, and formant/throat control, with a native editor and a
  live pitch-correction meter.
- **Rodhareist** — native editor with a signal-path view and a factory
  preset browser; 29 complete, loudness-matched factory rigs. The Shimmer
  reverb no longer runs away above about 30 % shimmer.
- **WayGate** — new plug-in with native and web editors, patch routing and
  meters. **67Clipper** and **VerbSpace** DSP reworked.
- **WrapSynth** — native editor and sample clearing.
- Built-in editors moved to native UI; VST3 hosting fixes.
- **Smoother controls** — built-in effect gains, mix and thresholds glide
  instead of stepping, and power/mode switches crossfade, so moving a knob
  no longer zips or clicks.
- **EQ-Z8** — the analyser draws with Canvas 2D where WebGL is unavailable.

## Routing

- **Plug-in MIDI output** can be routed to other tracks as their MIDI input.

## Build

- `xtask` limits parallel Cargo jobs by available memory and falls back to
  thin LTO on machines with less than 20 GiB free.
