## Licensing moved to the Launcher

Studio no longer activates itself. Open the **Futureboard Launcher** and
activate there; Studio reads the licence and comes up licensed with nothing
else to do. The License window inside Studio now explains what this computer
holds and hands off to the Launcher rather than asking for a key.

This also makes Studio's start unconditionally local — there is no licensing
network call on the startup path at all any more, so a slow or unreachable
service cannot delay the DAW opening.

**Licence files are sealed to the machine they belong to.** One `license.dat`
replaces the previous pair of files. A licence edited by hand, or copied here
from another computer, is recognised as exactly that and named, instead of
failing in a way nobody could act on. Existing licences are carried forward on
first start; you do not need to re-activate.

## Scrolling

Nested scroll areas no longer all move at once. Scrolling a list inside a panel
inside a dialog used to scroll all three on the same tick. Now the innermost
one that can still move takes the wheel, and once it reaches its end the scroll
chains outward the way it does everywhere else. Dialog backdrops stop the wheel
reaching the content behind them.

## macOS

Professional now builds for macOS: Apple silicon, Intel, and a universal image,
each signed and notarized. ASIO is a Windows driver model and stays
Windows-only, so a macOS Professional build ships licensing, the account layer
and the licensed update transport with CoreAudio underneath.
